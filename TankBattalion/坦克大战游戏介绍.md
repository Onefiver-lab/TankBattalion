# 坦克大战 TankBattalion

基于 Qt6 / QML / C++23 开发的坦克大战游戏，支持单人闯关、双人合作、PVP 对战三种模式，配有四档难度、存读档、粒子特效和暗色主题 UI。

---

## 技术栈

| 技术 | 版本/标准 |
|------|-----------|
| C++ | C++23 |
| Qt | 6.11+ |
| QML | Qt Quick 6 |
| 构建 | CMake 3.28+ |
| 输入处理 | TapHandler / PointerHandler（Qt Quick 6 输入处理器） |

## 核心架构

### MVC 分层

```
┌─────────────────────────────────────┐
│              QML 前端（View）         │
│  StartMenu / BattleField / HUD / ... │
└──────────────┬──────────────────────┘
               │ Q_PROPERTY / Q_INVOKABLE / 信号槽
┌──────────────┴──────────────────────┐
│         GameController（Controller）  │
│  游戏循环 · 碰撞检测 · 胜负判定        │
└──────────────┬──────────────────────┘
               │ 持有并管理
┌──────────────┴──────────────────────┐
│              数据模型（Model）        │
│  Tank · Bullet · MapManager          │
│  SettingsManager · SaveManager       │
└─────────────────────────────────────┘
```

### 游戏主循环

- **定时器**：QTimer，16ms 间隔（约 60 FPS）
- **帧时间**：QElapsedTimer 计算 deltaTime，上限 50ms 防止卡顿穿墙
- **流程**：更新玩家 → 更新敌人(AI) → 更新子弹 → 碰撞检测 → 清理销毁对象 → 通知 QML 刷新

### 碰撞检测

- 矩形相交检测（QRectF::intersects）
- 子弹 vs 墙壁：砖墙可击毁，钢墙不可破坏
- 子弹 vs 坦克：扣血、击毁触发爆炸特效
- 坦克 vs 墙壁：移动前记录旧位置，碰撞后回退

## 游戏模式

| 模式 | 说明 | 玩家1操作 | 玩家2操作 |
|------|------|-----------|-----------|
| 单人模式 | 消灭所有敌军坦克 | WASD + 空格 | — |
| 双人合作 | 两人合作对抗敌军 | WASD + 空格 | 方向键 + 回车 |
| PVP 对战 | 互相攻击，先击杀对方获胜 | WASD + 空格 | 方向键 + 回车 |

## 难度系统

| 难度 | 敌人数量 | 弹药限制 |
|------|----------|----------|
| 简单 | 3 | 无限 |
| 中等 | 6 | 无限 |
| 困难 | 12 | 100 发 |
| 地狱 | 20 | 50 发 |

## 功能特性

### 游戏功能
- 三种游戏模式（单人 / 双人合作 / PVP）
- 四档难度（简单 / 中等 / 困难 / 地狱）
- 敌军 AI（随机移动 + 随机射击）
- 砖墙可击毁，改变战场地形
- 爆炸粒子特效（大爆炸/小爆炸）
- 实时分数统计

### 存档系统
- JSON 格式存档，保存完整游戏状态
- 存档内容包括：地图、坦克位置/血量/弹药、子弹、分数
- 支持随时保存和继续上局

### 设置系统
- 音效开关与音量调节
- 全屏模式切换
- 历史最高分记录
- 一键清空设置与存档

### UI 设计
- 暗色主题（#0d0d0d / #1e1e1e / #2a9d8f）
- 开始菜单（模式/难度可视化选择）
- 暂停遮罩（半透明遮罩 + 操作按钮）
- 战况结算（得分展示 + 再来一局/返回菜单）
- 设置面板（音效/全屏/存档管理）
- 坦克精灵带血条、弹药显示、履带纹理
- 子弹带发光光晕，按发射者变色

## 关键类说明

### GameObject（基类）

所有游戏对象的基类，提供位置、方向、碰撞箱、激活状态等基础属性，定义了 `update()` 纯虚函数供子类实现。

### Tank

继承自 GameObject，表示坦克。区分玩家坦克和敌人坦克，玩家坦克由键盘控制，敌人坦克由 AI 驱动（定时随机改变方向和射击）。

### Bullet

继承自 GameObject，表示子弹。记录发射者身份（玩家1/玩家2/敌军），飞行超出边界后自动销毁。

### GameController

游戏核心控制器，管理所有游戏对象的生命周期。负责游戏主循环、碰撞检测、胜负判定、快照存读档。通过 Q_PROPERTY 和 Q_INVOKABLE 暴露给 QML 前端。

### MapManager

15×20 网格地图管理器。支持砖墙（可击毁）、钢墙（不可破坏）、空地三种地形。提供碰撞检测和子弹击中处理。

### SettingsManager

基于 QSettings 的设置持久化管理。管理音效开关、音量、全屏模式、历史最高分。

### SaveManager

基于 JSON 的游戏存档管理。可将完整游戏状态序列化为 QVariantMap，支持存入文件和读取恢复。
